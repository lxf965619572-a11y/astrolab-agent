# AstroLab 工作台界面设计 v2（参照 Claude 桌面端）

2026-11-05。照 Claude 桌面端的布局和交互，重新整理工作台的页面结构。本文写清每个区域放什么、点了去哪、各种状态怎么显示，按第 13 节的顺序实现。现有代码在 `app/src`，涉及的文件写在各节末尾。

## 0 原则

照 Claude 抄的是下面五条原则，不只是长相。界面上每个改动都用这五条检查：

1. **一个东西只有一个家，每个入口只去一个地方。**工程的全部任务在工程主页；所有工程的任务在“全部任务”；不出现两个入口去同一页、名字却不一样。
2. **容器的标题就是它的入口，时间线的末尾才放“查看全部”。**工程是容器，点工程名进工程主页，工程下面不放“查看全部”；“最近”是时间线，末尾放“查看全部”。
3. **新建和历史放在同一页。**工程主页上面是输入框，下面是这个工程的任务；点工程名既能马上写新任务，也能找旧任务。
4. **少字。**侧栏一行只放标题；状态只在需要注意时亮一个点；说明放悬停提示。
5. **正在发生的事不能找不到。**后台任务、等你回答的任务、没审核的产出，在侧栏和标题上都有标记。

## 1 概念对照

| Claude 桌面端 | AstroLab | 说明 |
|---|---|---|
| Project（项目） | 工程（项目文件夹） | 一个文件夹一个工程，任务在里面运行；同一文件夹一次一个任务，不同文件夹可以同时跑（最多 3 个） |
| Session / Chat | 任务 | 一次对话，有状态（进行中、等你决定、完成待审核、已提交……） |
| Chat / Cowork / Code 切换 | 任务模式 / 代码模式 | 任务模式做文档和图，代码模式做编码、单元测试、走查；侧栏和首页按当前模式过滤 |
| Artifacts | 产出 | 任务生成的文档、表格、图，跨工程浏览 |
| Customize | 技能与插件、知识库 | 各自保留独立页面 |
| Instructions / Context（项目右栏） | 工程说明、参考资料 | 工程主页右栏，第 3 阶段 |
| Scheduled | 不做 | 内网单机使用，暂无定时需求 |
| 权限模式（Manual 等） | 审核提交 | 智能体不能提交 Git；改动由用户在审核页提交，这条不变 |
| 模型选择 | 部门模型（只显示） | 模型由部门路由决定，界面只显示当前模型和连接状态，不提供切换 |

## 4 侧边栏

### 4.1 结构（从上到下）

```
[≡] [ 任务 | 代码 ]                 ← 顶部：收起按钮 + 模式切换
＋ 新任务                  Ctrl N
⌕ 搜索                    Ctrl K
▣ 工程
▤ 产出
◇ 技能与插件
□ 知识库
置顶 ▾                              ← 有置顶时才显示
  任务标题                    ●
工程 ▾                         ＋    ← 组名右边“＋”：打开项目文件夹
  ▸ 示例工程                   ●     ← 工程行：点名字进工程主页
      任务标题 1               ●
      任务标题 2
      任务标题 3
  ▸ 我的库
      ……
最近 ▾                              ← 两个以上工程有任务时才显示
  任务标题（工程名在悬停提示里）
  ……（10 条）
  查看全部                          ← 去“全部任务”
──────────────
(头像) 本机用户名        ● ⌄        ← 账户区：点开菜单
```

去掉现在顶部的“全部任务”入口：工程的任务点工程名看，所有工程的任务从“最近 → 查看全部”或搜索进。

### 4.2 工程行

- **点名字**：进工程主页。不是当前工程时，先切过去。
- **左边的三角**：展开或收起下面的任务（记住状态，现有 `sideFold`）。
- **悬停时右边“⋯”菜单**：在这里新建任务（进工程主页，光标在输入框）、置顶、打开文件夹（当前工程）、移出列表（当前工程不能移出）。复制路径在工程主页右栏。
- **状态点**：工程里有后台任务在跑时亮蓝点；有任务在等你回答时亮琥珀点（现有 `live`、`asking`）。
- **下面的任务**：当前工程列最近 5 条，其他工程 3 条。**不再放“查看全部 N 个”**。

### 4.3 任务行

- 一行只放标题，超长省略；悬停提示：工程名 · 环节 · 状态 · 开始时间。
- 右边状态点：见第 10 节。正常完成并已提交的不亮点。
- **单击**：打开任务。别的工程的任务，先切到那个工程。同一工程有任务在跑时，打开另一个任务进只读查看（现有）。
- **悬停时“⋯”菜单**（现有 `TaskMenu`）：打开、置顶（P）、重命名（R）、归档（A）、删除（D，进行中的不能删）。
- **双击标题**：直接重命名。

### 4.4 “最近”

- 所有工程的任务按开始时间倒序，最多 10 条；置顶的不重复出现。
- **只有一个工程有任务时不显示**（和工程下面那几条重复）。
- 末尾“查看全部”，去全部任务页。

### 4.5 底部账户区

- 显示本机用户名（没有登录，用操作系统用户名）。右边一个小点：有新版本时蓝点，模型连不上时红点。
- 点开菜单：
  - 设置（Ctrl ,）
  - 模型：部门模型 · <模型名> · 已连接 / 连不上（点了进设置的“模型”）
  - 检查更新 / 安装新版本
  - 皮肤：浅紫、奶油、黑橙（现有三套，直接列在菜单里）
  - 提示音：开、关
  - 帮助、关于 AstroLab

对应文件：`components/Shell.tsx`（`Sidebar`、`ProjRow`、`SideRow`、`TitleBar`），`components/Panels.tsx`（`SideRail`）。

```

│ 示例工程                                        │ 工程信息          │

│   ……                                           │                  │
```

- **标题区**：工程名（点了可改显示名）、路径和 Git 分支（小字）。
- **输入框**：和首页同一个组件，占位文字“在 <工程名> 里新建任务……”。进页面时自动聚焦，所以点工程名后可以直接打字，保留“点工程名就能新建”的习惯。
- **任务列表**：就是现在“任务历史”页（`HistoryView`）的内容搬过来。
  - 按类别筛选的标签条（现有）；
  - 本工程内搜索；
  - 每行：状态点、标题、类别、日期；悬停出现“⋯”菜单；
  - 已归档的折叠在最后。
- **右栏**：
  - 工程信息：路径（带“打开文件夹”按钮）、Git 分支、任务数、进行中几个；
  - 工程说明：写进每个任务第一条消息的工程约定，例如“目标平台 BM3803”，对应 Claude 的 Instructions；
  - 参考资料：每个任务默认带上的文件，对应 Claude 的 Context。
  - 实现（第 3 阶段）：工程说明点“编辑”就地改，最多 4000 字，存在工程记录里，写进每个任务第一条消息的【工程说明】（和本次要求冲突时先问）。参考资料只列工程内的相对路径（最多 50 个），第一条消息里列成【参考资料】“和本次工作相关时再读”，不直接塞内容，免得每个任务都多读一遍；已经在本次“相关文件”里的不重复列。改了立即对下一个任务生效。

对应文件：新增 `views/ProjectView.tsx`，复用 `LaunchView` 的输入框（抽成 `Composer` 组件）和 `HistoryView` 的列表（抽成 `TaskList` 组件）。

## 7 任务页（对话区）

### 7.1 布局

```
┌───────────────────────────────────────────────┬──────────────────┐
│ 示例工程 / 研制总结报告（XY-9 V1.02）  完成待审核  ⋯ ▣ │ 进度 4/5          │
│───────────────────────────────────────────────│  ✓ 生成信息表      │
│                          ┌──────────────────┐ │  ✓ 读数据包        │
│                          │ 用户的话（气泡）    │ │  ● 生成报告        │
│                          └──────────────────┘ │ 产出 3 个文件      │
│ 智能体的回复（正文，不加气泡）                    │  研制信息表.md     │
│ ▸ 读了 12 个文件、运行了 3 个命令（点开看）        │  ……报告.docx      │
│ ┌ 问题卡片：需要你决定 ─────────────────────┐   │ 用到的            │
│ │ 1. 系统测试是否参加？  ○ 我来提供 ○ …     │   │  技能 dev-summary │
│ │                         [提交回答]        │   │  知识 1 条        │
│ └──────────────────────────────────────┘   │ 审核与提交         │
│ ┈ 工作台提醒：请先列出步骤 ┈（灰色一行）         │  改动 3 个文件     │
│                                               │  [审核并提交]      │
│ ┌──────────────────────────────────────────┐ │                  │
│ │ 补充说明或下一步要求……                         │ │                  │
│ │ [＋] [@文件]                  [停止] / [发送] │ │                  │
│ └──────────────────────────────────────────┘ │                  │
└───────────────────────────────────────────────┴──────────────────┘
```

### 7.2 顶部

- 面包屑：`工程名 / 任务标题`。点工程名回工程主页；点标题直接改名。
  - 实现（第 3 阶段）：工程名做成标题上方的一行小字（带文件夹图标），标题保持大字，双击改名；不加“/”分隔符，单独一行时显得悬空。
- 状态标签：进行中、等你决定、完成待审核、已提交、中断、出错。
- 右边：“⋯”菜单（和侧栏任务菜单相同，另加“导出对话”“在资源管理器中打开产出目录”）和右面板开关（Ctrl Shift B）。

### 7.3 对话流

- **用户的话**：靠右的气泡。第一条显示用户原话；工作台附加的约定、技能、相关文件不显示，现有 `followUpDisplay` 已处理。
- **智能体的回复**：Markdown 正文，不加气泡；代码块带复制按钮。
- **工具调用**：连续的工具调用合成一行摘要，如“读了 12 个文件、运行了 3 个命令”。点开逐条显示：中文说明、参数、结果。写文件的那条带“查看改动”，点了在右面板打开 diff。进行中的那一条显示转圈和已用时间。
- **思考过程**：默认折叠成“思考了 12 秒”，点开看。
- **问题卡片**（`ask_user_question`）：
  - 嵌在对话流里；未回答时输入框上方也提示“智能体在等你回答”；
  - 选项单选或多选，每题都有“其他”可以自己写；
  - 选项标“（推荐）”的，推荐两个字用弱色显示，避免用户不看就点；
  - 回答后卡片收起，显示所选答案。
- **工作台插话**（计划提醒等）：灰色一行，不当成用户的话（现有）。
- **一步很长时**：超过 1 分钟显示“还在生成较长的内容”（现有）。
- **新内容来时自动滚到底**；用户往上翻时不自动滚，右下角出现“回到最新”按钮。
  - 实现（第 3 阶段）：按钮放在对话区底部居中（输入框上方），右下角会挡住正文的行尾。
- 实现（第 3 阶段）：连续的思考和工具调用合成一组，摘要如“读了 6 个文件、改了 5 个文件、运行了 1 条命令、思考 4 秒”；任务进行中最后一组默认展开，其余默认收起。问题卡片仍是浮在对话上方的卡片（现有），推荐项把“（推荐）”去掉，在选项名后加弱色小标签“推荐”。

### 7.4 输入框（固定在底部）

- 多行，最多 8 行高，超出后内部滚动。
- **Ctrl Enter 发送**；Enter 换行（现有约定，不改）。
- 输入“/”弹出技能选择（现有）；“@”弹出工程内文件选择；“＋”菜单：附件、选技能。
- **任务进行中**：发送键变成“停止”。这时输入的话作为补充说明插进当前这一轮（steer，现有），按钮显示“补充”。
- **任务结束后**：输入的话作为追问继续这个任务。
- 草稿按任务分别保存，切走再回来还在。

### 7.5 右面板

分节，每节可以折叠，宽度可拖（现有 `TaskSide`）：

| 节 | 内容 | 交互 |
|---|---|---|
| 进度 | 智能体的 todo 列表，完成打勾，当前一项高亮 | 只读 |
| 产出 | 本任务生成或修改的文件 | 点了在面板内预览（Markdown、表格、图片、SVG、Word 文本）；悬停：打开、打开所在文件夹、复制路径 |
| 用到的 | 技能、知识条目、资料条目、工具服务 | 点了打开对应的技能或条目 |
| 审核与提交 | 改动文件列表、+/- 行数 | “审核并提交”打开审核视图（diff + 提交说明），用户确认后提交；智能体不能提交 |

对应文件：`views/TaskView.tsx`（`ConvHead`、`Stream`、`ActRow`、`Composer`）、`views/TaskSide.tsx`、`components/QuestionCard.tsx`。

### 7.6 代码模式

布局相同，右面板多一节“文件”（现有 `CodeView` 的文件树和 `InfoColumn`）。代码模式的首页标题保持“在 <工程名> 上写代码”。

## 8 会话（任务）管理

| 操作 | 入口 | 行为 |
|---|---|---|
| 新建 | 侧栏“新任务”、Ctrl N、工程行“＋”、工程主页输入框 | 在当前或指定工程新建；同一工程有任务在跑时，提示“这个工程有任务在进行，结束后再开始，或换一个工程” |
| 打开 | 侧栏、工程主页、全部任务、搜索 | 见 4.3 |
| 置顶 / 取消 | 任务菜单、P | 进侧栏“置顶”组 |
| 重命名 | 任务菜单、R、双击标题、任务页面包屑 | 回车确认，Esc 取消 |
| 归档 | 任务菜单、A | 从侧栏和列表消失，工程主页底部“已归档”里还在 |
| 删除 | 任务菜单、D | 确认对话框；进行中的不能删；删记录不删产出文件（对话框里写明） |
| 停止 | 任务页“停止”、Esc（输入框为空时） | 停止当前一轮，状态变“中断”，可以追问继续 |
| 继续 | 任务结束后在输入框写追问 | 同一任务追加一轮；换环节（需求 → 设计）建议新建任务，输入框上方提示一次 |
| 并行 | 不同工程各开一个任务 | 最多 3 个同时进行，超出时提示；后台任务完成或提问时系统通知 + 侧栏亮点（现有） |
| 批量 | 全部任务页勾选 | 归档、删除 |

## 9 搜索（Ctrl K）

- 居中弹层，宽 640px，打开即聚焦输入框；Esc 关闭。
- **没输入时**：显示最近打开的 8 个任务，以及“全部任务”“打开项目文件夹”两个快捷项。
- **输入后结果分组**：
  - 任务：匹配标题和第一条消息，显示工程名和日期；
  - 产出文件：匹配文件名；
  - 工程：匹配名称和路径。
- **范围**：默认所有工程，Tab 切到“只搜当前工程”。
- **键盘**：↑↓ 选择，Enter 打开，Tab 切换范围，Esc 关闭。
- **打开产出文件**：打开产生它的任务（别的工程先切过去），右边“产出”里预览这个文件。
- **数据**：主进程读各工程的任务记录（`projects/<id>/tasks/*.json`）做本地搜索，不联网。

## 14 验收点

1. 点侧栏工程名进工程主页，光标在输入框里，直接打字回车就新建任务；下面能看到这个工程的全部任务。
2. 工程下面没有“查看全部”。“最近”末尾的“查看全部”去全部任务页，能看到两个工程的任务，可以按工程筛选。
3. 只有一个工程有任务时，侧栏不显示“最近”。
4. Ctrl K 能按标题找到任务、按文件名找到产出，Enter 打开；别的工程的任务打开时自动切工程。
5. 后台任务提问时：工程行和任务行亮琥珀点，系统通知带工程名，窗口标题有“（1）”。
6. 标题栏只剩拖动区；模型状态、更新、主题、提示音都能从账户区找到。
7. 设置页不显示 API Key 内容。
8. 窄窗口（1000px、760px）下右面板和侧栏按第 2 节自动收起，不出现横向滚动。
9. 工程主页右栏写工程说明、加参考资料后新建任务：第一条消息里有【工程说明】【参考资料】，对话里不显示这些附加内容。
10. 产出页能看到两个工程的文件，点一行打开对应任务并在右边预览；文件删掉后显示“已不在”，悬停按钮不出现。
11. 任务进行中往上翻，出现“回到最新”，点了回到底部；连续的读文件、运行命令合成一行摘要，能展开。
12. 问题卡片的推荐项显示为选项名后的弱色“推荐”标签；输入框为空时按 Esc 停止当前一轮。
