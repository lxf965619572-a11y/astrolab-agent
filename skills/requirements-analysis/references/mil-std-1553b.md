# MIL-STD-1553B 要点（需求分析用）

本文件整理需求分析中最常用到的 MIL-STD-1553B 规定，供核对任务书和 ICD 时使用。**引用标准条文时，只能引用本文件或输入材料中的内容**；本文件没有的条文，写“需核对标准原文”，不凭记忆写数值。部门使用 GJB 289A 等对应国军标时，以部门采用的标准文本为准。

## 1 基本参数

| 项目 | 规定 |
|---|---|
| 传输速率 | 1 Mbit/s，曼彻斯特 II 型双相码 |
| 字结构 | 每字 20 位时：3 位同步头 + 16 位数据 + 1 位奇校验。每个字自带奇偶校验，协议层没有“帧校验和” |
| 字类型 | 命令字、数据字、状态字 |
| 位序 | 每个字高位在前 |
| 多字数据的先后顺序 | **标准不规定**。32 位整数、单精度浮点数等跨 2 个字的数据，高字在前还是低字在前，必须由 ICD 规定 |

## 2 命令字

| 字段 | 位数 | 说明 |
|---|---|---|
| RT 地址 | 5 | 0～30 为 RT 地址；**31 为广播地址**（系统使用广播时），不能分配给某个 RT |
| T/R | 1 | 1 = RT 发送，0 = RT 接收 |
| 子地址/方式 | 5 | 1～30 为数据子地址；**0 和 31 都是方式码标识**，不能用于数据消息 |
| 数据字个数/方式码 | 5 | 数据消息为 1～32 个数据字（00000 表示 32）；**每条消息最多 32 个数据字** |

## 3 响应时间

- RT 状态字响应时间：**4.0～12.0 μs**，从收到的最后一个字的奇偶位中点量到状态字同步头中点。
- 该时间由 1553B 协议芯片（RT 接口硬件）保证，不是软件能控制的指标。任务书若把它写成软件需求，属于软硬件分工问题。

## 4 广播

- 广播命令发往 RT 地址 31，所有使能广播的 RT 接收。
- **RT 收到广播消息后不回送状态字**，只在状态字中置“广播命令接收”位；BC 需要确认时，可再用“发送状态字”或“发送上一条命令”方式码查询。
- 任务书若要求 RT 对广播回送状态字，违反标准。

## 5 方式码

T/R 位、是否带数据字、是否允许广播按下表。ICD 可以只使用其中一部分，也可以对允许广播的方式码规定“不广播”，这不算错误；但 T/R 位和是否带数据字不能与下表不同。

| 方式码 | T/R | 名称 | 数据字 | 允许广播 |
|---|---|---|---|---|
| 0 | 1 | 动态总线控制 | 无 | 否 |
| 1 | 1 | 同步（不带数据字） | 无 | 是 |
| 2 | 1 | 发送状态字 | 无 | 否 |
| 3 | 1 | 启动自测试 | 无 | 是 |
| 4 | 1 | 发送器关闭 | 无 | 是 |
| 5 | 1 | 取消发送器关闭 | 无 | 是 |
| 6 | 1 | 禁止终端标志位 | 无 | 是 |
| 7 | 1 | 取消禁止终端标志位 | 无 | 是 |
| 8 | 1 | 复位远程终端 | 无 | 是 |
| 16 | 1 | 发送矢量字 | 1 个（RT 发送） | 否 |
| 17 | 0 | 带数据字的同步 | 1 个（RT 接收） | 是 |
| 18 | 1 | 发送上一条命令 | 1 个（RT 发送） | 否 |
| 19 | 1 | 发送 BIT 字 | 1 个（RT 发送） | 否 |
| 20 | 0 | 选择的发送器关闭 | 1 个（RT 接收） | 是 |
| 21 | 0 | 取消选择的发送器关闭 | 1 个（RT 接收） | 是 |

9～15、22～31 为保留方式码。

要点：

- 带数据字的方式码**只有 1 个 16 位数据字**。例如用方式码 17 传时间，一次只能传 16 位。
- BIT 字的位定义由 ICD 或单机规定，标准不规定。
- 哪些方式码由协议芯片自动处理、哪些需要软件处理（如复位远程终端后软件做什么），由协议芯片和单机设计决定，需求中要写清楚。

## 6 双冗余总线

- 双冗余总线（A、B）同一时刻只用一条。**由 BC 决定在哪条总线上发命令**，某条总线上 RT 不响应时，由 BC 改用另一条总线重试。
- RT 在两条总线上都接收命令，并在收到命令的那条总线上应答（细节以标准原文为准）。
- 因此“RT 软件在通信失败后切换总线”这类要求通常是概念错误：RT 侧收不到状态字，也没有“通信失败”的直接判据，需要请总体澄清真实意图（例如是要求在一段时间内收不到任何命令时上报或复位）。
- 方式码 4、5、20、21 可由 BC 关闭或恢复 RT 在某条总线上的发送器，用于隔离故障。

## 7 需求分析中常见的 1553B 问题

| 问题 | 检查方法 |
|---|---|
| RT 地址取 31 或与 ICD 不一致 | 对照 ICD 总体参数 |
| 数据消息用了子地址 0 或 31 | 对照 ICD 子地址分配表 |
| 一条消息超过 32 个数据字 | 逐个子地址核对数据字个数与字定义表 |
| 32 位数据跨字顺序、浮点格式未规定 | 查 ICD 字定义表 |
| 广播后要求 RT 回送状态字 | 查任务书通信要求 |
| 把 4～12 μs 响应时间分给软件 | 查任务书接口和性能要求 |
| 用 1 个数据字的方式码传超过 16 位的数据 | 查时间同步等要求 |
| 要求 RT“切换总线” | 查冗余要求 |
| BIT 字、矢量字、状态字中“服务请求”“子系统标志”等位的用法未定义 | 查 ICD 方式码表和状态字使用说明 |
| BC 读取发送缓冲区时软件正在更新，数据一致性未规定 | 查遥测相关要求是否规定双缓冲或整帧更新 |
