# 文件头与函数头注释（示例版）

部门有注释模板时以部门模板为准。检查脚本识别下面的格式：函数定义前紧挨着的块注释里有“功能”和“设计”两项。

## 文件头

```c
/*
 * 文件名：rt_drv.c
 * 功能：  1553B RT 芯片驱动：复位、初始化、子地址收发、中断状态
 * 平台：  BM3803（SPARC V8），裸机
 * 设计：  rt1553-详细设计 第 4 章
 * 修改记录：
 *   2026-10-27  初版
 */
```

修改已有文件时，在修改记录中追加一行：日期、改了什么、依据（设计变更单号或问题报告号）。

## 函数头

```c
/*
 * 函数名：rt_reset
 * 功能：  复位 RT 芯片并等待就绪，超时返回错误
 * 设计：  4.2.1
 * 输入：  timeout_ticks  等待就绪的最长时间，单位 tick，1～1000
 * 输出：  无
 * 返回：  RT_OK          就绪
 *         RT_ERR_TIMEOUT 超时仍未就绪
 *         RT_ERR_PARAM   timeout_ticks 超出范围
 * 说明：  不可在中断中调用（会忙等）
 */
int32_t rt_reset(uint32_t timeout_ticks)
{
    ...
}
```

- “设计”写详细设计的条目号；一个函数实现多个条目时都写上，逗号分隔。设计里没有对应条目的函数（例如拆出来的内部辅助函数）写“设计：无（由 4.2.1 拆分）”。
- “输入”写取值范围和单位；范围来自设计。
- “返回”列出所有返回值及含义，与设计一致。
- 在中断中调用、需要在临界区内调用、会忙等等使用限制写在“说明”里。
