# 部门 C 编码规则（示例版）

本表是起步用的示例，按 GJB 8114《C/C++语言编程安全子集》的方向整理，应由部门编码规范负责人按 GJB 8114 原文和部门规范补充、修订。规则编号与代码走查检查表（`code-walkthrough` 技能）的编号相互独立；“检查”一栏表示哪个环节能发现：编译（`compile_check` 严格告警）、静态（Cppcheck）、脚本（本技能的 `check-code.mjs`）、人工。

## R1 声明与类型

| 编号 | 规则 | 检查 |
|---|---|---|
| R1.1 | 用定长整数类型（`uint8_t`、`int16_t`、`uint32_t` 等，`<stdint.h>` 或项目的类型头文件）；不用 `int`、`long` 表示有宽度要求的数据（`long` 在 SPARC 上 32 位，D2000 上 64 位） | 人工 |
| R1.2 | 每个函数都有原型；外部函数原型放在头文件里，`static` 函数在文件开头声明 | 编译 |
| R1.3 | 只在本文件使用的函数和全局变量加 `static` | 编译、人工 |
| R1.4 | 中断服务程序与主程序共享的变量、硬件寄存器声明为 `volatile` | 人工 |
| R1.5 | 变量在声明时或使用前的所有路径上初始化 | 编译、静态 |
| R1.6 | 不用八进制常量（`0` 开头），无符号常量加 `u` 后缀（`0x8000u`） | 人工 |
| R1.7 | 位域不用于与硬件或通信对端交换的数据（布局由编译器决定） | 人工 |

## R2 运算与转换

| 编号 | 规则 | 检查 |
|---|---|---|
| R2.1 | 不做隐式的截断和有符号/无符号混用；需要转换时显式转换，并在注释中写明取值范围依据 | 编译 |
| R2.2 | 位运算和移位只用于无符号数；移位位数小于类型宽度 | 编译、人工 |
| R2.3 | 除数和取模的模数在运算前确认不为 0 | 静态、人工 |
| R2.4 | 可能溢出的加法、乘法先检查范围，或按设计规定饱和、回绕 | 人工 |
| R2.5 | 浮点数不用 `==`、`!=` 比较，用容差 | 编译 |
| R2.6 | 运算优先级不明显时加括号；条件表达式中不写赋值 | 编译 |
| R2.7 | 魔数用有含义的宏或枚举（寄存器偏移、位定义、门限、超时） | 脚本 |

## R3 控制流

| 编号 | 规则 | 检查 |
|---|---|---|
| R3.1 | `switch` 必须有 `default`；每个 `case` 以 `break` 结束，确需贯穿的写注释 | 编译、脚本 |
| R3.2 | `if ... else if` 链以 `else` 结束（处理“不可能”的情况） | 人工 |
| R3.3 | 等待硬件、等待标志的循环必须有超时退出，超时后返回错误码 | 脚本、人工 |
| R3.4 | 不用 `goto`、`setjmp`/`longjmp` | 脚本 |
| R3.5 | 不用递归（栈深度不可预测） | 脚本 |
| R3.6 | 循环变量不在循环体内修改；循环次数有上限 | 人工 |
| R3.7 | 函数返回的错误码都要检查，不检查的显式写 `(void)` 并注释原因 | 静态、人工 |

## R4 指针与数组

| 编号 | 规则 | 检查 |
|---|---|---|
| R4.1 | 指针参数使用前判空（设计规定了怎么处理的按设计） | 静态、人工 |
| R4.2 | 数组下标和长度在使用前检查上限；`memcpy`、`memset` 的长度不超过目标大小 | 静态、人工 |
| R4.3 | 不用动态内存（`malloc`、`calloc`、`realloc`、`free`） | 脚本 |
| R4.4 | 不把字节缓冲区强制转换成多字节类型或结构体指针访问（SPARC 非对齐访问陷阱）；按字节组装 | 人工 |
| R4.5 | 不返回局部变量的地址 | 编译、静态 |

## R5 中断、并发与硬件

| 编号 | 规则 | 检查 |
|---|---|---|
| R5.1 | 中断服务程序短小：只做必须立即做的事，置标志或入队，其余在主循环处理；不调用不可重入函数 | 人工 |
| R5.2 | 主程序读写与中断共享的多字节数据、读改写操作时进入临界区（按模块惯例关中断或其他机制），临界区尽量短，成对退出 | 人工 |
| R5.3 | 寄存器访问通过模块统一的宏或函数，地址和位定义来自硬件接口文件 | 人工 |
| R5.4 | 通信报文的多字节字段显式按协议规定的字节序组装和解析（SPARC 大端，D2000 小端） | 人工 |
| R5.5 | 看门狗喂狗只放在设计规定的位置，不在等待循环里无条件喂狗 | 人工 |

## R6 注释与格式

| 编号 | 规则 | 检查 |
|---|---|---|
| R6.1 | 每个文件有文件头，每个函数（含 `static`）有函数头，格式见 comment-template.md | 脚本 |
| R6.2 | 函数头写明对应的详细设计条目号（追溯） | 脚本 |
| R6.3 | 注释说明“为什么”，不复述代码；寄存器操作、单位换算、取值范围依据要注释 | 人工 |
| R6.4 | 一行一条语句；`if`、`for`、`while` 的语句体都用大括号 | 人工 |
| R6.5 | 函数长度适中（建议不超过 100 行），圈复杂度过高的按设计拆分 | 人工 |
