# OC 输出控制器接口说明（摘录）

文件编号：PDU-FPGA-ICD-003　版本：V1.0　日期：2026-08-20

说明：本文件为详细设计练习用的虚构示例。

## 1 概述

OC 输出控制器由 FPGA 实现，驱动 8 路 OC 输出（OC0～OC7）。处理器通过 4 个 32 位寄存器访问控制器，基地址 0x80000300。

## 2 寄存器

| 偏移 | 名称 | 访问 | 说明 |
|---|---|---|---|
| 0x00 | OUT_STATE | 只读 | 位 i（i = 0～7）为 OCi 输出端的回读状态：1 为输出（高电平），0 为断开。位 8～31 读为 0 |
| 0x04 | OUT_SET | 只写 | 写 1 的位对应的通道置为输出；写 0 的位不受影响 |
| 0x08 | OUT_CLR | 只写 | 写 1 的位对应的通道断开；写 0 的位不受影响 |
| 0x0C | CTRL | 读写 | 位 0 为 EN（输出使能）：0 时全部通道被强制断开，并且写 OUT_SET 无效；1 时按 OUT_SET/OUT_CLR 输出。其余位保留，写 0 |

## 3 时序

1. 写 OUT_SET 或 OUT_CLR 后，OUT_STATE 在 **2 μs** 内反映输出端的实际状态。软件在写入后应至少等待 2 μs 再读 OUT_STATE。
2. 同时写 OUT_SET 和 OUT_CLR 的同一位时，结果不确定，软件应避免。

## 4 复位状态

控制器复位后 CTRL.EN = 0，全部通道断开，OUT_STATE 读为 0。
