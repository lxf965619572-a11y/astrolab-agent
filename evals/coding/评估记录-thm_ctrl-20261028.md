## 2 发现的问题

1. **评测脚本找错了工作区（已修）。**AstroLab 首次运行时把仓库的 `sample` 复制到数据目录 `workspace\sample`，之后智能体读写的是这份副本；`prepare.mjs`、`score.mjs` 原来只看仓库的 `sample`，所以评分报“没有 .c 文件”。改为按应用的规则查找数据目录（`lib.mjs` 的 `sampleWorkspace`）。
2. **智能体能读工作区外面的文件。**这次工作区里没有 `coding\thm_ctrl`（`prepare.mjs` 放错了地方），智能体就列出了 `D:\lixf\astrolab-agent` 和仓库的 `sample`，从那里复制了输入。没有读 `evals\`（答案表、隐藏测试），评分有效；但说明它**读得到**：同一台电脑上的其他工程、`config\local.env`（模型 API 密钥）都在可读范围内。放到 harness 精细化中处理：读取范围限制在工作区和技能目录。
3. **技能没有提示检查“异常时输出处于什么状态”。**Q2 漏掉。已在 SKILL.md 第 2 步加了这一检查，“常见错误做法”加一行（用通信中断、执行机构的例子，不用本用例的场景）。
4. 任务没有记录技能（`task.skill` 为空），模型第一步自己调用 `skill` 加载了编码技能，多一次往返。下次在起始页选“编码”技能再发。
