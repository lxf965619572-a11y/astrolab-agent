# thm_ctrl 热控加热回路控制 详细设计说明

> 虚构示例，用于评估编码技能。目标平台 BM3803（SPARC V8，大端，32 位，裸机），C99。

## 1 概述

thm_ctrl 控制 4 个加热回路。每个回路有主份、备份两个热敏电阻（12 位 ADC 采样），按温度上下限开关加热器；
传感器连续异常判故障并切到备份；加热器连续加热超过时限强制关断；遥测按固定格式组帧。

- 主程序每 1 s 调用一次 `thm_cycle()`。
- `thm_set_limits()` 由遥控指令处理调用，**可能在遥控中断里执行**；`thm_get_status()`、`thm_pack_tm()` 在主程序里调用。
- 硬件访问只通过 `thm_hw.h` 中的函数（ADC 读数、加热器输出、毫秒计时、关中断）。

## 2 接口

接口头文件 `include/thm_ctrl.h` 已经评审通过，**不得修改**；硬件接口 `include/thm_hw.h` 由驱动组提供。

| 编号 | 函数 | 说明 |
|---|---|---|
| D-01 | `void thm_init(void)` | 初始化全部回路 |
| D-02 | `int32_t thm_set_limits(uint8_t ch, int16_t tl, int16_t th)` | 设置回路温度下限、上限 |
| D-03 | `void thm_cycle(void)` | 周期处理：采样、判故障、选传感器、开关加热器、加热时限 |
| D-04 | `int32_t thm_get_status(uint8_t ch, thm_status_t *st)` | 读回路状态 |
| D-05 | `int32_t thm_pack_tm(uint8_t *buf, uint32_t len)` | 组遥测帧 |
| D-06 | `static int16_t thm_adc_to_temp(uint16_t raw)` | ADC 读数转温度 |
| D-07 | `static void thm_sensor_update(...)` | 一个传感器的有效性判断和故障计数 |

温度单位一律为 0.1 ℃（`int16_t`），无有效温度时为 `THM_TEMP_INVALID`（0x7FFF）。

## 3 数据

每个回路保存：温度下限 TL、上限 TH；主份、备份各自的连续异常计数、连续正常计数、故障标志；当前采用的传感器；
当前温度；加热器状态；本次开始加热的时刻；加热超时标志。

初始值（D-01）：TL = 50（5.0 ℃），TH = 150（15.0 ℃）；计数、故障标志、超时标志清零；采用主份；温度为 THM_TEMP_INVALID；加热器关。

`thm_set_limits()` 写、`thm_cycle()` 读的 TL、TH 和超时标志是中断与主程序共享的数据。

## 4 处理

### 4.1 D-01 thm_init

1. 按第 3 节初始值设置 4 个回路。
2. 对 4 个回路依次调用 `thm_heater_out(ch, 0)`。

### 4.2 D-02 thm_set_limits

按以下顺序检查，遇到第一个不满足的就返回对应错误码，不修改任何数据：

1. `ch >= THM_CH_NUM` → 返回 `THM_ERR_CH`。
2. `tl >= th` → 返回 `THM_ERR_PARAM`。
3. `tl < -500` 或 `th > 500`（即允许范围 -50.0 ℃～+50.0 ℃）→ 返回 `THM_ERR_RANGE`。

全部满足时：进入临界区，写入 TL、TH，清除该回路的加热超时标志，退出临界区，返回 `THM_OK`。

### 4.3 D-06 thm_adc_to_temp

`temp = (int32_t)raw * 1650 / 4096 - 500`，先乘后除，整数除法（向零取整），再减 500。例：raw = 1241 → 1241 × 1650 / 4096 = 499 → -1（-0.1 ℃）。

### 4.4 D-07 传感器有效性和故障

ADC 读数在 **50～4000（含两端）** 之间为本次有效，否则为本次异常（开路或短路）。

- 本次异常：连续正常计数清零；连续异常计数加 1（到 255 后不再加）；连续异常计数 **达到 3** 时置故障标志。
- 本次有效：连续异常计数清零；已判故障的，连续正常计数加 1（到 255 后不再加），**达到 5** 时清除故障标志、连续正常计数清零；未判故障的连续正常计数保持 0。

计数是“连续”的：中间出现一次相反的结果就从 0 重新计。

### 4.5 D-03 thm_cycle

对每个回路 ch = 0～3 依次：

1. 读主份、备份：`thm_adc_read(ch, 0)`、`thm_adc_read(ch, 1)`，分别按 4.4 更新。
2. 选传感器：
   - 主份未判故障且本次有效 → 采用主份，温度为主份读数转换的值；
   - 否则，备份未判故障且本次有效 → 采用备份，温度为备份读数转换的值；
   - 否则本周期温度为 THM_TEMP_INVALID，“采用的传感器”保持上一周期的值。
3. 开关加热器（只在温度有效时判断；温度无效时加热器状态保持不变）：
   - 温度 **≤ TL** → 开；
   - 温度 **≥ TH** → 关；
   - 介于两者之间 → 保持。
   - 该回路加热超时标志已置位时，一律为关。
4. 加热时限：加热器从关变开时，记下 `thm_tick_ms()` 为开始时刻。加热器为开、且 `thm_tick_ms() - 开始时刻 ≥ 600000`（10 min）时：
   关加热器，置加热超时标志。超时标志在 `thm_set_limits()` 成功时清除。毫秒计数是 32 位无符号数，会回绕，用无符号减法计算经过时间。
5. 输出：**每个周期**都调用 `thm_heater_out(ch, 状态)`，不论状态有没有变化（防止输出锁存器单粒子翻转）。

读 TL、TH、超时标志时进入临界区，复制到局部变量后退出，再做比较。

### 4.6 D-04 thm_get_status

1. `ch >= THM_CH_NUM` → 返回 `THM_ERR_CH`。
2. `st == NULL` → 返回 `THM_ERR_PARAM`。
3. 在临界区内复制：`temp`、`sensor`（0 主份、1 备份）、`heater`（0 关、1 开）、`fault`（位 0 主份故障、位 1 备份故障、位 2 加热超时），返回 `THM_OK`。

### 4.7 D-05 thm_pack_tm

1. `buf == NULL` → 返回 `THM_ERR_PARAM`。
2. `len < THM_TM_LEN` → 返回 `THM_ERR_BUF`。
3. 按下表填写，返回写入的字节数 `THM_TM_LEN`（19）。

| 字节 | 内容 |
|---|---|
| 0 | 同步字 0xA5 |
| 1 | 回路数 4 |
| 2 + 4i、3 + 4i | 回路 i 的温度，**大端**（高字节在前），补码；无效为 0x7FFF |
| 4 + 4i | 回路 i 状态：位 0 加热器开、位 1 采用备份、位 2 主份故障、位 3 备份故障、位 4 加热超时，其余位 0 |
| 5 + 4i | 保留，填 0 |
| 18 | 校验：字节 0～17 的**累加和**，取低 8 位 |

## 5 异常处理

- 参数错误按各函数的检查顺序返回错误码，不修改数据、不调用硬件接口。
- 不使用动态内存，不使用递归，等待硬件的循环必须有退出条件（本模块无需等待）。
