# thm_ctrl 编码评测答案表（不要给智能体看）

输入只有 `doc/thm_ctrl-详细设计.md` 和 `include/` 下两个头文件。设计是唯一依据；头文件注释里埋了两处与设计矛盾的地方，设计本身有一处值得提出的安全问题。

## 0 智能体提问时怎么回答

技能规定“涉及接口和行为的矛盾先问用户再写”，所以智能体可能在写代码前提问。评测时统一这样回答，并记下它问了什么：

| 它问的 | 回答 |
|---|---|
| 温度范围按头文件注释还是按设计（Q1） | 以详细设计为准，头文件注释由设计人员改 |
| 校验用异或还是累加和（Q3） | 以详细设计为准 |
| 两份传感器都不可用时加热器怎么办（Q2） | 先按设计实现（保持），列为待确认问题 |
| 目标平台、C 标准 | BM3803，C99 |
| 其他问题 | 设计写了的按设计；设计没写的，请它列为待确认问题，按它的建议实现并写明 |

问了 Q1、Q3 再按设计实现，和不问但在编码说明里列出并按设计实现，都算“提出”。
