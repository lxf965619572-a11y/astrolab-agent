# 热控单元与平台通信协议

文件编号：TCU-PLT-ICD-002　版本：V1.1　日期：2026-09-25

说明：本文件为概要设计练习用的虚构示例。

## 1 物理层

**1.1**　RS422 异步串行通信，波特率 57600 bps，8 位数据位，1 位停止位，无校验。

**1.2**　平台是通信的发起方。平台发送的相邻两帧之间间隔不小于 20 ms。

## 2 帧格式

**2.1**　帧格式：

| 字段 | 长度（字节） | 说明 |
|---|---|---|
| 帧头 | 2 | 0xEB、0x90 |
| 帧类型 | 1 | 见 2.3 |
| 数据长度 | 1 | 数据字段的字节数 N |
| 数据 | N | 见第 3～5 章 |
| 校验 | 2 | CRC-16/CCITT，多项式 0x1021，初值 0xFFFF，计算范围从帧类型到数据末尾 |

**2.2**　多字节数据高字节在前。

**2.3**　帧类型：

| 帧类型 | 名称 | 方向 | 数据长度 N |
|---|---|---|---|
| 0x01 | 遥控帧 | 平台 → 热控单元 | 2 |
| 0x02 | 遥测查询帧 | 平台 → 热控单元 | 0 |
| 0x03 | 参数上注帧 | 平台 → 热控单元 | 80 |
| 0x81 | 遥测应答帧 | 热控单元 → 平台 | 72 |

## 3 遥控帧

**3.1**　数据为指令码（1 字节）和参数（1 字节）：

| 指令码 | 指令 | 参数 |
|---|---|---|
| 0x11 | 加热器接通 | 加热器编号 1～16 |
| 0x12 | 加热器断开 | 加热器编号 1～16 |
| 0x13 | 加热器全部断开 | 0x00 |
| 0x21 | 切换到自主控温模式 | 0x00 |
| 0x22 | 切换到遥控模式 | 0x00 |

## 4 参数上注帧

**4.1**　数据为 16 组控温参数，按 H1～H16 的顺序排列，每组 5 字节：控温点编号（1 字节）、下限阈值（2 字节）、上限阈值（2 字节）。

## 5 遥测应答帧

**5.1**　数据共 72 字节：

| 偏移 | 长度 | 内容 |
|---|---|---|
| 0 | 64 | T1～T32 的测量值，每路 2 字节，高 4 位为 0 |
| 64 | 2 | 加热器状态，bit n − 1 对应 Hn，1 表示接通 |
| 66 | 1 | 工作模式：0x01 自主控温，0x02 遥控 |
| 67 | 1 | 遥控接收计数 |
| 68 | 1 | 遥控错误计数 |
| 69 | 1 | 遥控拒绝计数 |
| 70 | 1 | 复位计数 |
| 71 | 1 | 备用，填 0x00 |

**5.2**　平台发出遥测查询帧后等待 20 ms，20 ms 内没有收到应答帧的第一个字节时，判为应答超时。
