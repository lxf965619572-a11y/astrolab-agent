# Word 模板目录

`docgen` 服务从这里读取 Word 模板（`.docx` 或 `.dotx`），也可以用环境变量 `DOCGEN_TEMPLATE_DIR` 指定其他目录（多个用分号分隔）。

## 部门模板（2026-11-03 起）

`部门-*.docx` 由 `node mcp\docgen\make-dept-templates.mjs` 从 `文档模板\` 下的部门模板生成，部门原模板不改动。部门模板更新后重新运行该命令。

生成时保留封面、内容概要页、更改栏、修改历史、目录页、页面设置和样式，做了这些改动：

- 封面各栏换成字段：`{{编号}}` `{{密级}}` `{{阶段标记}}` `{{页数}}` `{{型号代号}}` `{{文档名称}}` `{{编制单位}}` `{{编写}}` `{{校对}}` `{{审核}}` `{{标审}}` `{{批准}}`。“文件名称”一栏用 `{{文档名称}}`，docgen 自动填 Markdown 文首的一级标题。
- 内容概要页：`{{内容提要}}`、`主题词：{{主题词}}`。部门原件这一页的标题是“内容概要”，Word 版模板误为“内容提要”，生成时已改回；字段名仍叫 `{{内容提要}}`。各 Skill 生成的报告在文首注释里给出这两个字段的值，`render_docx` 时用 `fields` 传入。
- 修改历史表清空示例行。
- 目录页保留模板原有的目录域；目录页之后的模板正文（填写说明和示例）换成 `{{正文}}` 一段。

西文字体：生成时英文、数字统一用 Times New Roman（docgen 改写模板样式中的西文字体，并给生成的每段文字设置），中文字体沿用模板；某个模板不需要时，在同名 .json 中写 `"latinFont": null`，或写其他字体名。

没有提供的字段填“【待补充】”并黄色高亮，由用户在 Word 中补（编号、密级、编写、审核等不应由智能体填写）。

工作底稿（需求分析记录、设计记录、单元测试记录、走查记录、静态分析记录、确认测试记录、研制信息表）不套部门模板，需要 Word 时用 `demo-gjb438b` 或直接导出。

## 占位符

用 Word 打开模板，在相应位置直接输入（三个都是可选的）：

- `{{正文}}`：单独占一段。生成的正文插在这里。没有这一段时，模板原有正文会被整体替换，页面设置和页眉页脚保留。
- `{{目录}}`：单独占一段。替换为 Word 目录域，打开文档时 Word 会提示“是否更新域”，选“是”即生成目录。模板里已经有目录域时就不用加。
- `{{字段名}}`：封面、页眉、页脚中需要填写的内容。字段名可以自己定，智能体会用 `list_templates` 查到。

## 样式识别与映射

`docgen` 按以下规则自动识别模板样式：

| 用途 | 自动识别的样式名 |
|---|---|
| 正文 | 模板的默认段落样式（通常是“正文”） |
| 标题 1–9 | Word 内置“标题 1”…“标题 9”，或大纲级别为 1–9 级的段落样式 |
| 题注 | “题注”（caption） |
| 表格文字 | “表格文字”“表格内容” |
| 代码 | “代码” |
| 表格 | “网格型”（Table Grid） |

部门模板的标题样式没有自动编号，Markdown 标题里手写的章节号原样保留。

模板用的是自定义样式名（如“1级标题”“表格正文”）时，在模板旁边放一个**同名的 .json 文件**指定映射，值可以是样式名或样式 ID：

```json
{
  "description": "部门软件需求规格说明模板（2024 版）",
  "styles": {
    "body": "正文",
    "heading1": "1级标题",
    "heading2": "2级标题",
    "caption": "表题",
    "tableText": "表格正文",
    "code": "程序代码",
    "table": "部门表格"
  }
}
```

`description` 会在 `list_templates` 中显示。`make-dept-templates.mjs` 每次运行会重写 `部门-*.json`，要加样式映射时改脚本中的说明或在运行后再改。
