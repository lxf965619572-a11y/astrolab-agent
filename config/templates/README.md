# Word 模板目录

`docgen` 服务从这里读取 Word 模板（`.docx` 或 `.dotx`），也可以用环境变量 `DOCGEN_TEMPLATE_DIR` 指定其他目录（多个用分号分隔）。

现在只有一个演示模板 `demo-gjb438b.docx`，由 `node mcp\docgen\make-demo-template.mjs` 生成，**不是部门正式模板**。

## 进内网后接入部门模板

1. 把部门正式模板复制到本目录。文件名就是模板名，建议按文档类型命名，如 `SRS-软件需求规格说明.docx`、`SDD-软件设计说明.docx`。
2. 在模板里加占位符。用 Word 打开模板，在相应位置直接输入（三个都是可选的）：
   - `{{正文}}`：单独占一段。生成的正文插在这里。没有这一段时，模板原有正文会被整体替换，页面设置和页眉页脚保留。
   - `{{目录}}`：单独占一段。替换为 Word 目录域，打开文档时 Word 会提示“是否更新域”，选“是”即生成目录。模板里已经有目录域时就不用加。
   - `{{字段名}}`：封面、页眉、页脚中需要填写的内容，如 `{{软件名称}}`、`{{文件编号}}`、`{{版本}}`、`{{密级}}`。字段名可以自己定，智能体会用 `list_templates` 查到。
3. 删除模板中的示例正文和填写说明，只保留封面、目录页、正文占位段落。
4. 在 DSH 中让智能体调用 `list_templates`，确认字段和标题样式都识别到了。

## 样式识别与映射

`docgen` 按以下规则自动识别模板样式：

| 用途 | 自动识别的样式名 |
|---|---|
| 正文 | 模板的默认段落样式（通常是“正文”） |
| 标题 1–9 | Word 内置“标题 1”…“标题 9”，或大纲级别为 1–9 级的段落样式 |
| 题注 | “题注”（caption） |
| 表格文字 | “表格文字”“表格内容” |
| 代码 | “代码” |
| 表格 | “网格型”（Table Grid） |

标题样式带多级自动编号时，Markdown 标题里手写的章节号会被去掉，由 Word 自动编号；手写章节号与自动编号的顺序对不上时（如跳过了某章），会保留手写章节号并关闭该标题的自动编号。

部门模板用的是自定义样式名（如“1级标题”“表格正文”）时，在模板旁边放一个**同名的 .json 文件**指定映射，值可以是样式名或样式 ID：

```json
{
  "description": "部门软件需求规格说明模板（2024 版）",
  "styles": {
    "body": "正文",
    "heading1": "1级标题",
    "heading2": "2级标题",
    "heading3": "3级标题",
    "heading4": "4级标题",
    "caption": "表题",
    "tableText": "表格正文",
    "code": "程序代码",
    "table": "部门表格"
  }
}
```

`description` 会在 `list_templates` 中显示，建议写明适用的文档类型和版本。
