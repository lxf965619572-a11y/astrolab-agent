# 阶段 0 离线安装包验证记录（2026-10-26）

环境：开发电脑打包（commit 86b152d），在 Windows 沙盒（Windows 11，WDAGUtilityAccount，只有 Windows PowerShell 5.1，无 Git、无 VC++ 运行库）中安装和自检。

## 结论

关口 G0 的“离线安装包在断网的干净环境中装上并跑通”达到：安装不需要管理员权限、不联网；除模型接口外自检全部通过；引擎启动 2.4～3.5 秒。

| 项目 | 结果 |
|---|---|
| 安装包大小 | 1.47 GB（DSH 0.69 GB、GCC 0.50 GB、Node 0.09 GB、Cppcheck 0.05 GB、其余 0.13 GB），满足 NFR-12（≤ 2 GB） |
| 安装 | `install.cmd` 复制到 `%LOCALAPPDATA%\Programs\AstroLab`，不需要管理员权限 |
| 断网自检（沙盒无网卡，模型 ENOTFOUND） | Node、DSH、PowerShell 5.1、GCC、Cppcheck、utest / docgen / cppcheck 三个服务自检、引擎握手全部通过；Git 未带（警告） |
| 引擎启动（从安装目录运行） | 3544 ms、2360 ms；工具服务模块加载 63 ms；utest 自检 2.1 秒 |

## 发现的问题与处理

1. **Cppcheck 在干净 Windows 上起不来**（退出码 0xC0000135，找不到 DLL）：它依赖 VC++ 运行库，开发电脑上有、新电脑上没有。处理：打包时把 `msvcp140*.dll`、`vcruntime140*.dll`、`concrt140.dll` 放到 `cppcheck.exe` 旁边（应用本地部署），用户不用另装运行库。
2. **从沙盒的映射文件夹直接运行时，引擎启动 33～40 秒**，联网、断网都一样；从安装目录（本地磁盘）运行是 2～3 秒。原因是映射文件夹每次读文件都要跨虚拟机，而 DSH 启动要读上万个小文件。正式使用都在本地磁盘，不受影响；但说明**软件不能装在网络共享盘上运行**，内网部署说明里要写明（更新包可以放共享盘，安装时复制到本地）。
3. 只有 Windows PowerShell 5.1 时 DSH 能退回使用它，自检正常；智能体用它执行命令的情况，留待联网沙盒中跑一次模型任务时确认。
4. Git 是否随安装包提供，取决于内网电脑是否已统一安装（待确认问题）；打包脚本有 `-IncludeGit` 选项。
