# Win10 真机安装验收（待办第 2 条）

目的：在一台**干净的 Win10** 上，按“新用户 30 分钟内装好、配置并跑完一个示例，不需要管理员权限”（实施方案 8.3 节、关口 G4）计时走一遍。到现在只在 Windows 沙盒里验证过（10-29）。沙盒里没有域策略、杀毒软件，用户也是管理员，真机上常见的问题（防火墙、SmartScreen、杀毒、组策略、普通用户权限）都没碰到过。

顺带把待办第 4 条里只能在真机上看的几项（托盘、通知、开机自启、别的电脑登录）一起看了，省得再装一次。

## 0 在开发电脑上打包（约 10 分钟）

```powershell
cd D:\lixf\astrolab-agent
git pull                                   # 确认在最新提交
cd app; npm install; cd ..                 # 依赖有变化时
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1      # DSH 版本和 config\dsh.json 不一致时打包会报错，先跑这个
powershell -ExecutionPolicy Bypass -File packaging\build-offline.ps1
```

- 部门服务器上已有更新用的共享文件夹（例如 `\\fileserver\astrolab\release`）的，打包时加 `-UpdateDir <路径>`，第 3 条“软件更新”就能直接接着做；还没有的先不加，以后在 `local.env` 里填 `ASTROLAB_UPDATE_DIR`。
- 包在 `runtime\dist\AstroLab`，上次（10-28）约 1.8 GB。打包结束会打印各部分大小和提交号，把 `runtime\dist\results\build.log` 留着。
- 有时间的话先双击 `runtime\dist\sandbox-offline.wsb` 在沙盒里装一次、跑 `check.cmd`，确认包本身没问题再上真机。

**拷到 Win10 上**：文件很多（上万个），直接复制文件夹很慢。建议用 7-Zip 压成一个 `.7z` 或 `.zip`，拷过去再解压到本地盘（如 `D:\AstroLab-安装包`）。**不要放在网络共享盘上直接装或运行**（DSH 启动要读上万个小文件，共享盘上要 30 秒以上）。

## 2 计时：装好、配置、跑完一个示例（目标 30 分钟内）

从“安装包已经在这台电脑上”开始计时。每一步记开始时间，碰到问题写在“问题”列，**不要当场改代码**，记下来回到开发电脑上改。

| # | 步骤 | 看什么 | 开始时间 | 问题 |
|---|---|---|---|---|
| 1 | 解压安装包 | 用时 | | |
| 2 | 双击 `install.cmd` | 不要求管理员；有没有 SmartScreen“已保护你的电脑”、杀毒拦截；开始菜单和桌面有 AstroLab 图标 | | |
| 3 | 运行安装目录里的 `check.cmd`（`%LOCALAPPDATA%\Programs\AstroLab\check.cmd`） | 自检报告每一行（Node、DSH、PowerShell、GCC、Cppcheck、各工具服务、引擎握手）；模型接口这时还没配，失败是正常的 | | |
| 4 | 从开始菜单打开 AstroLab | 首次启动用时；任务栏图标是不是 AstroLab 的 | | |
| 5 | 按界面提示在 `%LOCALAPPDATA%\AstroLab\local.env` 填模型地址、模型名和 Key（**Key 由你自己填**），重启工作台 | 设置 → 模型里点“检测”，模型、上下文、工具三项都通过 | | |
| 6 | 打开“示例工程”，代码模式发起：`走查 src/tm_frame.c，出走查报告` | 任务跑完；右边“产出”里能预览报告；用到了 Cppcheck | | |
| 7 | 停表 | 总用时 | | |

示例任务选代码走查，是因为它短（几分钟），又能顺带用到模型、Cppcheck 和文档服务。

## 3 顺带看（不计时，待办第 4 条里只能在真机上看的）

| 项目 | 怎么看 | 结果 |
|---|---|---|
| 关窗口缩到托盘 | 点窗口的 ×，托盘里还在；托盘菜单能打开、能退出 | |
| 通知 | 新建一个定时任务，点“立即运行”，完成时右下角弹通知，点通知打开那次运行 | |

| 网页访问（本机） | 设置 → 网页访问 → 打开，用本机浏览器开 `http://127.0.0.1:8620`，输入口令登录 | |
