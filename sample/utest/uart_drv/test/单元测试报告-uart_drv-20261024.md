# uart_drv 单元测试报告

## 1 概述

- 被测文件：`utest/uart_drv/src/uart_drv.c`（SHA-1 `94e340757d72`，头文件 `utest/uart_drv/include/uart_drv.h`、`uart_reg.h`）
- 设计依据：`utest/uart_drv/doc/uart_drv-详细设计.md`（示例文档，文件未标注编号和版本）
- 目标平台：BM3803（SPARC V8）裸机
- 测试框架：手写驱动 + 桩（utest.h，`framework: "c"`）
- 编译器：C:\msys64\ucrt64\bin\gcc.exe 16.2.0（支持 MC/DC 测量）
- 编译选项和宏：`-std=c89 -Wall -Wextra -O0 -g --coverage -fcondition-coverage`；未定义型号配置宏
- 运行记录：`D:\lixf\astrolab-agent\sample\.utest\uart_drv\last-run.json`
- 替换的头文件、特殊处理：
  1. `include/uart_reg.h` 由 `test/hw/uart_reg.h` 替换（`includeDirs` 中 `test/hw` 排在 `include` 之前）。寄存器偏移和位定义按设计 1.1～1.3 节抄写，只把 `UART_RD`/`UART_WR` 改为调用 `test/stub_hw.c` 中的寄存器模型。模型记录每次写入的（偏移、值、写入时刻的 CTRL、写入时刻的 SCALER），STATUS 读值由用例脚本给定，DATA 读从用例压入的接收队列取出，写 DATA 记入发送记录。与目标机的差别：STATUS 的读值不随"写 1 清除"变化。
  2. `sys_ticks()`（`test/stub_sys_time.c`）、`irq_lock()`/`irq_unlock()`（`test/stub_irq.c`）用桩代替，桩记录调用次数和参数。
  3. 测试文件 `#include "../src/uart_drv.c"`，目的是把模块内部 static 状态复位为上电初值（只用于设置用例初始状态；预期结果全部按设计推出）。被测代码未做任何修改。

## 5 疑似缺陷

| 编号 | 用例 | 现象 | 设计依据 | 疑似位置 | 建议 |
|---|---|---|---|---|---|
