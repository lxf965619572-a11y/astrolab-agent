# rt1553 模块详细设计（示例，虚构）

本模块是单元测试练习用的虚构模块：1553B 远程终端（RT）通信，由两个单元组成：

| 单元 | 源文件 | 头文件 | 职责 |
|---|---|---|---|
| RT 芯片驱动 | `src/rt_drv.c` | `include/rt_drv.h` | 复位和配置协议芯片，建立子地址查找表，读取描述符堆栈，读写共享 RAM 中的数据块 |
| RT 消息处理 | `src/rt_msg.c` | `include/rt_msg.h` | 中断中取出收到的消息；主循环中读取接收数据、写入发送数据、转发遥控指令、判断总线静默 |

芯片的寄存器、共享 RAM 地址和读写宏定义在 `src/rt_hw.h`（**与 `rt_drv.c` 在同一目录**），只由 `rt_drv.c` 使用。系统时间和中断开关由 BSP 提供（`include/sys.h`），遥控指令分发由遥控处理模块提供（`include/tc_dispatch.h`），都不属于被测模块。

调用关系：

| 调用者 | 被调用 | 执行环境 |
|---|---|---|
| 初始化程序 | rt_drv_init、rt_msg_init | 初始化 |
| 1553B 中断（芯片中断） | rt_msg_isr → rt_drv_irq_status、rt_drv_next_desc、rt_drv_read、sys_ticks | 中断 |
| 主循环 | rt_msg_poll → rt_msg_get、tc_dispatch、irq_lock、irq_unlock、sys_ticks | 主循环 |
| 遥测模块 | rt_msg_put → rt_drv_write_tx；rt_msg_status | 主循环 |

单元测试的预期结果以本文件为准。

## 1 硬件接口（rt_hw.h）

### 1.1 寄存器

寄存器和共享 RAM 都是 16 位。本模块通过 `RT_REG_RD(偏移)`、`RT_REG_WR(偏移, 值)` 读写寄存器，通过 `RT_RAM_RD(字地址)`、`RT_RAM_WR(字地址, 值)` 读写共享 RAM。

| 偏移 | 名称 | 访问 | 说明 |
|---|---|---|---|
| 0x01 | CFG1 | 读写 | bit0 RT：1 为 RT 方式；bit1 ENH：1 为增强方式 |
| 0x03 | START | 只写 | bit0 RESET：写 1 软件复位，复位完成后 STAT.READY 置 1；bit1 RUN：写 1 开始工作 |
| 0x04 | STAT | 只读 | bit0 READY：复位完成；bit1 BUSY：正在传输消息；bit9～5：BUSY 为 1 时正在传输的子地址 |
| 0x05 | IMASK | 读写 | bit0：消息结束（EOM）中断使能 |
| 0x06 | ISTAT | 只读，读后清除 | bit0 EOM：有消息结束 |
| 0x07 | STKPTR | 只读 | 芯片下一次写描述符的字地址（0x0000～0x00FF，按 4 字递增，到 0x0100 回到 0x0000） |
| 0x08 | ADDR | 读写 | bit4～0：RT 地址；bit5：校验位 |

RT 地址校验：ADDR 的 bit5～0 中共有**奇数个 1**（奇校验）。例如地址 0（无 1）校验位为 1；地址 1（1 个 1）校验位为 0；地址 3（2 个 1）校验位为 1。

### 1.2 共享 RAM

| 字地址 | 内容 |
|---|---|
| 0x0000～0x00FF | 描述符堆栈：64 个描述符，每个 4 字，循环使用 |
| 0x0140 + n | 接收子地址 n 的数据块地址（查找表） |
| 0x0160 + n | 发送子地址 n 的数据块地址（查找表） |
| 0x0400 + (n − 1) × 32 | 接收子地址 n（1～4）的数据块，32 字 |
| 0x0500 + (n − 1) × 32 | 发送子地址 n（1～2）的数据块，32 字 |

描述符：第 0 字块状态字（bit15 EOM，bit12 ERR：消息有错），第 1 字时间标签，第 2 字数据块地址，第 3 字收到的命令字。芯片每处理完一条消息写一个描述符，然后 STKPTR 加 4。

命令字：bit15～11 RT 地址，bit10 T/R（0 为接收，即 BC 发给 RT；1 为发送），bit9～5 子地址，bit4～0 数据字数（0 表示 32）。子地址 0 和 31 为方式码，本模块不处理。

## 2 rt_drv 单元

### 2.1 常量和数据

| 名称 | 值 | 说明 |
|---|---|---|
| RT_ADDR_MAX | 30 | 允许的最大 RT 地址（31 为广播） |
| RT_RX_SA_MAX | 4 | 接收子地址 1～4 |
| RT_TX_SA_MAX | 2 | 发送子地址 1～2 |
| RT_MAX_WC | 32 | 一条消息的最大字数 |
| RT_RESET_TIMEOUT | 10 | 复位完成等待时间，tick（1 ms） |
| 返回码 | RT_OK 0、RT_ERR_PARAM −1、RT_ERR_TIMEOUT −2、RT_ERR_BUSY −3 | |

| 变量 | 类型 | 说明 |
|---|---|---|
| s_next | static uint16_t | 下一个待读描述符的字地址，0x0000～0x00FC，只在中断中（rt_drv_next_desc）和初始化中访问 |

### 2.2 rt_drv_init

原型：`int rt_drv_init(uint8_t rt_addr)`。初始化时调用一次。

1. rt_addr 大于 30 时返回 RT_ERR_PARAM，不访问任何寄存器。
2. 写 START = RESET（0x0001）。
3. 记下 start = sys_ticks()，循环读 STAT：READY 为 1 时退出循环；每次 READY 为 0 时，若 sys_ticks() − start（32 位无符号相减）**大于或等于 10**，返回 RT_ERR_TIMEOUT（此时不进行后续配置）。
4. 写 CFG1 = RT | ENH（0x0003）。
5. 写 ADDR = rt_addr | 校验位（1.1 节奇校验）。
6. 接收查找表：子地址 1～4，写 RAM[0x0140 + n] = 0x0400 + (n − 1) × 32。
7. 发送查找表和数据块：子地址 1～2，写 RAM[0x0160 + n] = 0x0500 + (n − 1) × 32，并把该数据块的 32 个字清零。
8. s_next = 0。
9. 写 IMASK = EOM（0x0001）。
10. 写 START = RUN（0x0002）。**必须在第 4～9 步全部完成之后**。
11. 返回 RT_OK。

### 2.3 rt_drv_next_desc

原型：`int rt_drv_next_desc(rt_desc_t *d)`。在中断中调用，取出下一个描述符。

1. d 为 NULL 时返回 RT_ERR_PARAM。
2. 读 STKPTR，取 bit7～0 得 ptr。
3. ptr 等于 s_next 时，没有新的描述符，返回 0，d 不变。
4. 否则从 RAM[s_next]～RAM[s_next + 3] 依次读出 bsw、ttag、ptr、cmd 到 d。
5. s_next 加 4，到 0x0100 时回到 0x0000（与 0x00FF 按位与）。
6. 返回 1。

### 2.4 rt_drv_read

原型：`void rt_drv_read(uint16_t addr, uint16_t *buf, uint8_t wc)`。从共享 RAM 字地址 addr 起读出 wc 个字到 buf。buf 为 NULL 时不做任何操作；wc 为 0 时不读。

### 2.5 rt_drv_write_tx

原型：`int rt_drv_write_tx(uint8_t sa, const uint16_t *buf, uint8_t wc)`。主循环中调用，把发送数据写入子地址 sa 的发送数据块。

1. buf 为 NULL、sa 不在 1～2、wc 不在 1～32 时返回 RT_ERR_PARAM，不访问寄存器和 RAM。
2. 读 STAT。BUSY 为 1 **且** bit9～5 等于 sa（BC 正在读这个子地址）时返回 RT_ERR_BUSY，不写数据块。BUSY 为 1 但传输的是其他子地址时，照常写入。
3. 把 buf[0]～buf[wc − 1] 写入 RAM[0x0500 + (sa − 1) × 32 + i]。
4. 返回 RT_OK。

### 2.6 rt_drv_irq_status

原型：`uint16_t rt_drv_irq_status(void)`。返回读 ISTAT 的值（芯片读后清除）。

## 3 rt_msg 单元

### 3.1 常量和数据

| 名称 | 值 | 说明 |
|---|---|---|
| RT_SA_TC | 1 | 遥控指令子地址 |
| RT_TX_TRIES | 3 | 发送数据写入最多尝试次数 |
| RT_LINK_TIMEOUT | 1000 | 总线静默判定时间，tick |

| 变量 | 说明 | 访问者和保护 |
|---|---|---|
| s_rx[5][32]、s_rx_wc[5]、s_rx_new[5] | 每个接收子地址（1～4）最近一条消息的数据、字数、“有新数据”标志 | 中断写；rt_msg_get 在关中断内读和清标志 |
| s_msg_cnt、s_err_cnt | 正确消息计数、错误消息计数，16 位，到 0xFFFF 后保持 | 中断写；rt_msg_status 在关中断内读 |
| s_last_rx | 最近一次收到正确消息时的 tick | 中断写；rt_msg_poll 在关中断内读 |
| s_link_lost | 总线静默标志 | 只在主循环中访问 |

### 3.2 rt_msg_init

原型：`void rt_msg_init(void)`。清除各子地址的字数和新数据标志、两个计数、静默标志；s_last_rx = sys_ticks()。

### 3.3 rt_msg_isr

原型：`void rt_msg_isr(void)`。1553B 中断服务程序中调用。

1. 调用 rt_drv_irq_status()，EOM 位为 0 时直接返回（不读描述符）。
2. 循环调用 rt_drv_next_desc(&d)，直到返回值不为 1。对每个描述符：
   1. bsw 的 ERR 位为 1：错误消息计数加 1（饱和），**丢弃该消息**（不更新数据、不更新 s_last_rx、不计入正确消息），处理下一个描述符。
   2. 否则：正确消息计数加 1（饱和），s_last_rx = sys_ticks()。
   3. 从 cmd 取子地址 sa（bit9～5）和字数 wc（bit4～0，**0 表示 32**）。
   4. cmd 的 T/R 位为 0（接收）且 sa 在 1～4 时：调用 rt_drv_read(d.ptr, s_rx[sa], wc)，s_rx_wc[sa] = wc，s_rx_new[sa] = 1。新消息覆盖该子地址未读的旧消息。
   5. T/R 位为 1（发送消息）或 sa 为其他值（含方式码 0、31）：只计数，不读数据。

### 3.4 rt_msg_get

原型：`int rt_msg_get(uint8_t sa, uint16_t *buf, uint8_t *wc)`。主循环中调用，读取子地址 sa 最近一条未读消息。

1. buf 或 wc 为 NULL、sa 不在 1～4 时返回 RT_ERR_PARAM，不关中断。
2. key = irq_lock()。
3. 该子地址没有新数据：irq_unlock(key)，返回 0，buf 和 *wc 不变。
4. 否则复制 s_rx_wc[sa] 个字到 buf，*wc = s_rx_wc[sa]，清除新数据标志，irq_unlock(key)，返回 1。

每条返回路径上 irq_lock 和 irq_unlock 都成对调用，irq_unlock 的参数是配对的 irq_lock 的返回值。

### 3.5 rt_msg_put

原型：`int rt_msg_put(uint8_t sa, const uint16_t *buf, uint8_t wc)`。遥测模块在主循环中调用。

调用 rt_drv_write_tx(sa, buf, wc)：返回 RT_ERR_BUSY 时再次调用，**最多调用 3 次**；返回其他值时立即停止。返回最后一次 rt_drv_write_tx 的返回值。参数检查由 rt_drv_write_tx 完成。

### 3.6 rt_msg_poll

原型：`void rt_msg_poll(void)`。主循环每轮调用一次。

1. 调用 rt_msg_get(1, buf, &wc)，返回 1 时调用 tc_dispatch(buf, wc) 转发遥控指令（数据和字数与收到的一致）；返回 0 时不调用。
2. 关中断读出 s_last_rx（irq_lock / irq_unlock 成对）。
3. sys_ticks() − s_last_rx（32 位无符号相减，tick 回绕时结果仍正确）**大于或等于 1000** 时 s_link_lost = 1，否则 s_link_lost = 0。

### 3.7 rt_msg_status

原型：`void rt_msg_status(rt_status_t *st)`。st 为 NULL 时直接返回。否则在关中断内复制两个计数，再复制 link_lost。
